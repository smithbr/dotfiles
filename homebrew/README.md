# homebrew/

Brewfiles and `brew.sh`. A persona's `brew` and `brew_optional` keys pick which Brewfiles install ([root `AGENTS.md`](../AGENTS.md)); `df-add brew NAME` adds a package for you ([`scripts/README.md`](../scripts/README.md)). `brew.sh` installs Homebrew if needed, runs `brew bundle install --no-upgrade` on each `brew` Brewfile (so a Brewfile is a plain bundle file, and an entry that only applies to macOS sits in an `if OS.mac?` block, as the casks in `Brewfile.core` do), offers the not-yet-installed entries of each `brew_optional` Brewfile in a picker on macOS (inside an install, `install.sh` asks that question up front: `brew.sh --pending` lists the entries and `DOTFILES_BREW_PICKS` carries the answer), trusts tap-qualified entries first (Homebrew 7 refuses untrusted taps), and ends with `brew cleanup`. `-n` reports what would be installed. A role's `brew` Brewfiles join the persona's. Upgrades are `os-update`'s job.

- Place a new package by role, and never install the same tool through two managers. apt (`scripts/bootstrap/linux/apt-packages.txt`) takes what needs root or runs before brew: compilers via `build-essential`, `curl`, the login shell, and network utilities that want raw sockets. `homebrew/Brewfile.core` is the default for userland CLI tools on both platforms (fresher than Debian stable, and covers tools apt lacks); other Brewfiles hold persona-specific, GUI, or macOS-only apps and casks. Vault tooling (Obsidian, restic) is in `Brewfile.home` only: a server gets none of it from this repo, and the vault's own scripts install what its backups need. System daemons (Docker, Tailscale, Pi-hole, and Unbound from apt beside Pi-hole) come from the vendor's official installer through a script in `scripts/bootstrap/linux/`, applied as an optional install or a role ([`roles/`](../roles/README.md)); on a Mac, Docker and Tailscale are the macOS picker's, and the install scripts skip a tool Homebrew already put in place. Bootstrap runs apt first, then brew; `tests/brew.bats` fails when the git config references a tool no Brewfile installs.
