# homebrew/

Brewfiles and `brew.sh`. A persona's `brew` and `brew_optional` keys pick which Brewfiles install ([root `AGENTS.md`](../AGENTS.md)); `df-add brew NAME` adds a package for you ([`scripts/README.md`](../scripts/README.md)).

- Place a new package by role, and never install the same tool through two managers. apt (`scripts/bootstrap/linux/apt-packages.txt`) takes what needs root or runs before brew: compilers via `build-essential`, `curl`, the login shell, and network utilities that want raw sockets. `homebrew/Brewfile.core` is the default for userland CLI tools on both platforms (fresher than Debian stable, and covers tools apt lacks); other Brewfiles hold persona-specific, GUI, or macOS-only apps and casks. Vault tooling (Obsidian, restic) is in `Brewfile.home` only: a server gets none of it from this repo, and the vault's own scripts install what its backups need. System daemons (Docker, Tailscale) come from the vendor's official apt repo through a script in `scripts/bootstrap/linux/`, registered as an optional install in `setup.sh`. Bootstrap runs apt first, then brew; `tests/brew.bats` fails when the git config references a tool no Brewfile installs.
