# My dotfiles

macOS and Debian/Ubuntu dotfiles managed with [chezmoi](https://www.chezmoi.io/).

```bash
git clone https://github.com/smithbr/dotfiles.git ~/.dotfiles
~/.dotfiles/install.sh
```

Run `~/.dotfiles/install.sh --help` for installation options.

See [AGENTS.md](AGENTS.md) for maintenance and quality rules.
